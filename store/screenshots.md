# 스크린샷 구성안 5장 (PLAN §15.5)

실제 게임 화면에 짧은 한국어 문구를 얹는다. 세로 비율.

| # | 단계 | 담을 장면 | 문구 |
|---|---|---|---|
| 1 | 1-1 | 스윙바이 궤적이 행성을 돌아 목적지로 들어가는 순간 | 한 번 쏘고 끝 |
| 2 | 1-1 조준 중 | 발사대 행성 위 우주선과 예측선 | 보이는 대로 날아갑니다 |
| 3 | 2-1 | 블랙홀의 보라색 중력 범위와 급하게 꺾인 궤도 | 블랙홀도 길이 됩니다 |
| 4 | 3-1 | 외계인의 붉은 사격 범위를 비껴 가는 궤적 | 붉은 원을 피해서 |
| 5 | 5-1 | 넓은 맵과 미니맵 | 넓은 항로를 미니맵으로 |

찍는 법: `npm run preview` 로 띄우고 폰 크기(예: 400×860)로 창을 맞춘 뒤
각 단계에서 캡처한다. HUD 가 나오는 편이 실제 화면답다.
