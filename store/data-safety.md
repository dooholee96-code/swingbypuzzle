# 데이터 보안·개인정보 라벨 메모 (PLAN §15.5)

구글 플레이 "데이터 보안" 양식과 애플 "개인정보 라벨"에 적을 항목.
**게임 코드가 수집하는 것은 없다.** 수집 주체는 광고 SDK 뿐이다.

## 게임이 직접 하는 것

| 항목 | 값 | 근거 |
|---|---|---|
| 수집 | 없음 | 서버가 없다. 네트워크 호출이 광고 SDK 말고는 없다 |
| 공유 | 없음 | |
| 기기에 저장 | 클리어 기록·설정·힌트 (localStorage) | 기기를 떠나지 않는다 |
| 전송 중 암호화 | 해당 없음 (전송이 없다) | |
| 삭제 요청 | 브라우저 사이트 데이터 삭제 / 앱 데이터 삭제로 즉시 | |

## 광고 SDK 가 하는 것

구글 플레이 양식에서는 **광고 SDK 의 수집도 앱의 수집으로 신고해야 한다.**
아래는 착수 시점의 AdMob 공식 안내를 기준으로 한 초안이며, **제출 직전에
현재 안내를 다시 확인할 것.**

| 데이터 종류 | 수집 | 공유 | 목적 |
|---|---|---|---|
| 기기 또는 기타 ID (광고 ID) | 예 | 예 | 광고, 분석 |
| 대략적 위치 (IP 기반) | 예 | 예 | 광고 |
| 앱 상호작용 | 예 | 예 | 광고, 분석 |

- 사용자가 데이터 수집을 선택 해제할 수 있는가: **예** (기기 설정의 광고 맞춤설정)
- 데이터가 전송 중 암호화되는가: **예** (SDK 가 처리)

## 연령·등급

- 타깃 연령: **만 13세 이상.** 아동을 타깃층에 넣으면 가족 정책과
  아동 대상 광고 설정이 추가로 필요해진다(§15.5).
- 콘텐츠 등급 설문: 폭력·성적 내용·약물 없음. **"광고 포함" 표시.**
- 인앱 구매: 없음.
