**여기에 계정 정보·키·광고 단위 ID 를 넣지 않는다**(§0.8, §19).

## 사용자가 해야 하는 것

이 저장소에서 할 수 없는 일들이다.

1. **개인정보처리방침의 문의처 이메일**을 채운다.
2. **H5 Games Ads 도메인 승인 신청** — AdSense/Ad Manager 계정으로
   `dooholee96-code.github.io` 를 등록한다. 심사에 시간이 걸리므로 먼저 낸다.
3. 승인 뒤 퍼블리셔 ID 를 **GitHub Actions 시크릿 `VITE_H5_CLIENT`** 로 넣는다.
   저장소 파일에 적지 않는다.
4. 구글 플레이 개발자 계정, 앱 ID 확정, 업로드 키 생성·보관.
5. AdMob 앱·광고 단위 생성 (M12 의 앱 빌드에서 쓴다).
6. 연령 등급 설문, 데이터 보안 양식 제출 — `data-safety.md` 를 근거로.
7. **저장소 Settings → Pages → Source 를 "GitHub Actions"** 로 한 번 바꾼다.
   이것을 하지 않으면 워크플로가 통과해도 사이트가 뜨지 않는다.
8. **실기기 확인** (§18) — 중급·저사양 안드로이드에서 60fps, 무음 모드와
   이어폰에서 소리, 타이틀 데모와 조준 감도. 여기서는 실기기가 없다.
9. 폰으로 **40단계를 직접 클리어**해 본다 (§17 M10 완료 기준).
   검증기는 "풀린다"까지만 보장한다 — 재미있는지는 사람이 판단한다.
